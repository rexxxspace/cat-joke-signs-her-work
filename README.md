# Cats Sign Their Work

A make.fun entry for **The One-Line Cat Joke That Lands**: one joke about
cats, a single line under 200 characters, and nothing else in the entry.

## The joke

> My cat knocked my glass off the table while staring straight at me — not
> breaking eye contact is how cats sign their work.

122 characters, one line. The setup is the crime every cat owner knows;
the turn is that the unbroken stare is not defiance for its own sake — it
is a signature. She is not sorry. She is an artist, and the work is hers.

## How it works

- `main.ts` (Node 22, standard library only) writes the joke, exactly as it
  stands in the source, to `/output/entry.txt` — deterministic, no network,
  the same bytes on every run.
- Run it locally with an output folder of your choice:

  ```
  mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
  ```
